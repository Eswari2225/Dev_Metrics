## 📌 About the Project

**Dev Metrics Dashboard** is a web-based project focused on visualizing software development performance and engineering productivity metrics.

The dashboard aims to make development data easier to understand through a clear interface and visual representations. It explores how metrics, including DORA metrics, can help teams understand delivery performance and identify areas for improvement.

The project is built with a modern JavaScript frontend setup using React and Vite and is deployed on Netlify.

## 🎯 Project Objectives

- Visualize software development performance in an accessible format.
- Make engineering metrics easier to interpret.
- Explore DORA metrics and their role in measuring software delivery.
- Present development-related information through a dashboard interface.
- Build a responsive and maintainable frontend application.

## 📚 What Are DORA Metrics?

DORA metrics are commonly used to understand software delivery performance. The four traditional key metrics are:

| Metric | What It Measures |
|---|---|
| Deployment Frequency | How often changes are deployed to production |
| Lead Time for Changes | How long changes take to reach production |
| Change Failure Rate | The proportion of deployments that result in failures |
| Mean Time to Restore | How quickly service is restored after a failure |

These metrics provide different perspectives on delivery speed and stability. Accurate calculations require suitable deployment and incident data.

## ⚙️ Getting Started

Follow these steps to run the project locally.

### Prerequisites

Install the following:

- [Node.js](https://nodejs.org/)
- npm, included with Node.js
- Git

### 1. Clone the repository

```bash
git clone https://github.com/Eswari2225/Dev_Metrics.git
```

### 2. Navigate to the project directory

```bash
cd Dev_Metrics
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the application

Open the local URL printed in your terminal by Vite, commonly:

```text
http://localhost:5173/
```

## 🏗️ Build for Production

To create a production build, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
